# Frontend — ComproYa en Línea

Todavía no existe proyecto. Se scaffoldea con Next.js (App Router, TypeScript) siguiendo `../docs/arquitectura.md` (sección 4) y se construye pantalla por pantalla siguiendo `../docs/plan-de-trabajo.md`, en el mismo orden de sprints del canon.

Las pantallas del Cliente digital y las de los roles internos (Coordinador de Canal Digital, Gerente de Tienda, Analista de Marketing) viven en este mismo proyecto, separadas por ruta y por rol autenticado — no son dos aplicaciones distintas.

Cada pantalla que se construya debe corresponder a un mockup ya producido según `../docs/mockups-plan.md` (código `P-n`). No se construyen pantallas que no estén en ese plan sin antes agregarlas ahí y revisar que el caso de uso exista en el canon.
