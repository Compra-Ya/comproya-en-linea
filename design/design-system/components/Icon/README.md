# Icon

Íconos de línea de 24 × 24, trazo 1,7 y `currentColor`, en el estilo del ícono de carrito original.

## Qué aporta quien lo usa

`name` (uno de: cart, search, check, check-circle, alert, warn, info, clock, store, user, package, receipt, ticket, card, bank, chevron-left, chevron-right, minus, plus, x), `size` (18 por defecto), `title` solo si el ícono va sin texto (no debería).

## Reglas

- Todo ícono lleva una etiqueta de texto visible al lado (UT-02). Un ícono solo es decorativo y se oculta a lectores de pantalla.
- Sin íconos de categoría que sean el mismo dibujo para todas (A-04): si no hay ícono propio, solo el nombre.
- Sin emoji.
