# ProductImage

Foto del producto en contenedor 1:1, contenida sin recortar (las fotos horizontales y verticales dejan franjas blancas). Si falta o falla, el placeholder con el nombre de la categoría.

## Tamaños

`card` (fluido 1:1), `thumb` (64 px, carrito), `mini` (46 px, resumen y complementarios).

## Reglas

- Texto alternativo: el nombre del producto; placeholder: "Sin foto: {producto}".
- Sin zoom: hay una sola resolución de 300 a 800 px.
