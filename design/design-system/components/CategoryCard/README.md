# CategoryCard

Categoría con foto redonda y nombre debajo; es el elemento del carrusel.

## Qué aporta quien lo usa

`name` (en español), `image` (foto de `public/categorias`), `href`, `count` opcional, `active` en la página de esa categoría.

## Reglas

- Foto 96 px (72 px a 390 px) con anillo blanco; al pasar el mouse o en la categoría actual, el anillo pasa a naranja y sube 2 px.
- El nombre ocupa hasta dos líneas.
