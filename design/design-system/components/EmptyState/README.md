# EmptyState

Estado vacío con una ilustración sencilla (ícono grande dentro de un círculo naranja claro), título, una frase y la acción para salir de ahí.

## Qué aporta quien lo usa

`icon` o `imageSrc` (foto redonda, por ejemplo la de una categoría), `title`, `text`, `action` (un `Button` primary).

## Reglas

- Nunca una pantalla vacía sin salida: siempre hay `action`.
- Usos: carrito vacío ("Ver productos"), búsqueda sin resultados ("Ver todos los productos"), Mis pedidos vacío, Mis pedidos sin sesión ("Iniciar sesión").
