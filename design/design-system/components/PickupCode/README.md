# PickupCode

El código de retiro en el comprobante, con su vencimiento y la regla de un solo uso al lado (regla de negocio, UT-05).

## Qué aporta quien lo usa

`code`, `expiresOn` (fecha escrita con día de la semana), `branch`, `city`.

## Reglas

- Siempre junto al código: "Vence el {fecha} (5 días calendario). Se puede usar una sola vez."
- El título de la pantalla que lo contiene es "Comprobante de tu pedido"; sobre el código, "Tu código de retiro".
- Sin "identificador de correlación" ni otros datos internos.
