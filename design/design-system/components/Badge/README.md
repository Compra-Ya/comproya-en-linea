# Badge

Etiqueta corta de estado; el texto siempre está visible y el color nunca es la única señal.

## Qué aporta quien lo usa

`tone` (`neutral`, `info`, `ok`, `warn`, `danger`, `brand`), `children` (dos a cuatro palabras), `icon` (si no, un punto).

## Reglas

- Para estados de pedido usa `OrderStatus`.
- `brand` marca un producto complementario sin darle protagonismo.
