# Checkbox

Casilla con etiqueta clicable para el consentimiento del registro.

## Qué aporta quien lo usa

`label`, `checked`, `onChange`, `error` opcional (por ejemplo "Debes aceptar el tratamiento de datos para crear tu cuenta.").

## Reglas

- La etiqueta es una frase completa que dice a qué se compromete el usuario.
- El borde de la casilla y su marca usan `orange-600` (3:1 o más sobre `surface`).
