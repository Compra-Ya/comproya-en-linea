# Card

Contenedor de sección con borde `line`, radio `radius-lg` y título opcional.

## Qué aporta quien lo usa

`title`, `aside` (un enlace o insignia a la derecha del título), `children`.

## Reglas

- Separa con borde, no con sombra. Sin borde lateral de color.
- Relleno `space-5` × `space-6`; `space-4` a 390 px.
